# Отдельная версия Семицветика

Ветка: `version/site-rebuild`. Концепция сохраняет исходный многоцветный цветок и тёплый характер центра: кремовая основа, янтарные, оранжевые, фиолетовые и зелёные акценты, настоящие фотографии и портреты. Реализован единый Flask/Jinja-интерфейс с Onest и общей формой обращения. Production не изменялся и не перезапускался.

## Объём

- Семь основных страниц: `/`, `/programmy/`, `/pedagogi/`, `/o-centre/`, `/ceny/`, `/kontakty/`, `/meropriyatiya/`.
- Восемь маршрутов программ используют один шаблон и предварительный выбор программы в общей форме.
- Новости, страница новости и существующие статьи; новый резервный текст «Данные заявки».
- Один lead flow через `/api/lead`, включая обычный POST без JavaScript, состояния отправки/ошибки/успеха и контекст программы в `Lead.note`.
- Произвольные опубликованные Page за пределами основных страниц используют прежний `content_page.html` и `hydrate_blocks`: сохраняется полный контракт редактора JSON-блоков. Опубликованная privacy Page также имеет приоритет над резервным текстом.

## Локальный запуск

Из корня этой версии используйте проектное виртуальное окружение и локальную конфигурацию/базу. Не запускайте seed поверх существующих данных.

```bash
source .venv/bin/activate
python -m flask --app wsgi.py run --host 127.0.0.1 --port 5095
```

Если окружения ещё нет: `python3 -m venv .venv`, затем после активации `python -m pip install -r requirements.txt`. Настройте локальный `.env` по `.env.example`, не публикуя его содержимое. Адрес: `http://127.0.0.1:5095/`.

## Перед публичным запуском

`SiteSetting.program_terms_verified` по умолчанию false скрывает цены, возраст и длительность до подтверждения центром. Наследованные контакты, программы и публикации Event требуют редакционной проверки. Резервный текст privacy описывает фактическую работу формы и не заменяет утверждённую юридическую политику; существующий опубликованный документ сохраняется.

`noindex,nofollow` в новом базовом шаблоне намеренно оставляет отдельную версию вне индекса. До публикации необходимо восстановить и проверить исходное SEO structured data и правила индексации. Это ограничение нового шаблона, не утверждение о запрете индексации всех совместимых старых Page.

Фотографии занятий унаследованы из существующих публичных ресурсов проекта; портреты педагогов предоставлены пользователем. Onest размещён локально: файлы извлечены из существующего концепта, лицензия OFL сохранена рядом со шрифтом. Проверка прав на публикацию всех материалов остаётся частью выпуска.

Дизайнерская свобода пользователя не трактуется как подтверждение деловых/юридических фактов или результатов пользовательского исследования. Deployment требует отдельного явного запроса и стандартного production checklist репозитория.
