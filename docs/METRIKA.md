# Яндекс Метрика

Номер счётчика задаётся в `YANDEX_METRIKA_ID` окружения либо в настройке сайта `yandex_metrika_id`; окружение имеет приоритет. Допускается только положительный числовой ID. Без него код счётчика не выводится. Новый счётчик автоматически не создаётся.

Счётчик исключён из localhost, страниц входа/администрирования и режима заглушки. Включены карта кликов, отслеживание ссылок и точный показатель отказов; Вебвизор отключён. Имена, телефоны и содержимое форм не передаются в параметры целей.

В интерфейсе Метрики нужно создать цели типа «JavaScript-событие» с идентификаторами:

| Идентификатор | Событие |
| --- | --- |
| goal_lead_start | Первое взаимодействие с формой |
| goal_lead_submit | Сервер подтвердил сохранение заявки |
| goal_phone_click | Нажатие ссылки телефона |
| goal_telegram_click | Переход в Telegram |
| goal_whatsapp_click | Переход в WhatsApp |

Аналитика не управляет результатом формы: блокировка счётчика или исключение его JS не превращают сохранённую заявку в ошибку. Неполный телефон проверяется перед сетевым запросом; при исправлении сообщения валидации сбрасываются.

Подключение проверено с синтетическим номером и подменой сети: инициализация, цель успешной заявки, отсутствие персональных параметров и сохранение сообщения об успехе при сбое аналитики. Подтверждение реального поступления визитов выполняется после получения номера и разрешённого выпуска на сайт.

Документация: [инициализация](https://yandex.ru/support/metrica/en/code/counter-initialize), [JavaScript-цели](https://yandex.ru/support/metrica/en/general/goal-js-event).
